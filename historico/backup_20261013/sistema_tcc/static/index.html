Como funciona

  1. O controlador confere as etapas existentes.
  2. Agenda a primeira etapa pendente com dependências prontas.
  3. Executa o script e acompanha seu log.
  4. Confere o relatório final antes de seguir.
Preparação automática termina nas partições. O treino é um experimento solicitado pelo botão da etapa 6.
